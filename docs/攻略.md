# 警察故事3　流程攻略

> **這份沒有實機驗證過。**
>
> 內容整理自 1993 年《軟體世界》第 35–37 期的〈警察故事3 完全攻略〉三期連載。
> 本專案在中文化過程中**沒有**把遊戲從頭玩到尾，所以下面每一步的正確性、
> 以及當年攻略是否遺漏了會扣分的動作，都還沒被驗證。
>
> 照著走卡住、或發現步驟有誤，請開 issue——那正是這份文件需要的東西。
>
> 原文是第一人稱敘事，這裡改寫成路線式，方便對照。人名地名沿用原文的英文拼寫。
> 掃描件見 [`scans/`](scans/)。

PQ3 的計分邏輯是「照警察程序辦事就給分」，所以流程裡有不少「不做不會死、但會扣分」的動作。
要輸入代碼的地方（罰單、收押、無線電）請查 [`手冊要點.md`](手冊要點.md) 的三張表。

## 第一天：復職

**警局二樓**

1. 進左手第一間辦公室，看桌上公文箱的紙條——交警組組長要你找女警 **Pat Morales** 談話
   （她勤務中出言不遜遭民眾申訴）。
2. 到簡報室找 Morales，請她簡報後到你辦公室。
3. 拿講桌旁的簡報表，主持下午簡報。
4. 回辦公室，Morales 已在等。問完經過後給組長答覆（原文說選**左起第三個選項**），
   把答覆放上組長桌。
5. 公文箱裡出現電腦卡申請表。

**三樓電腦／管制中心**

6. 把申請表交給主任，拿到**電腦卡**。

**一樓更衣室**

7. 進男更衣室，打開自己的置物櫃（中央那排）。原文說**密碼寫在警徽（或警員證）右上角**
   ——這是查手冊型防拷的一環。拿走**手電筒、警棍、筆記簿**。
8. 走廊對面的儲藏室：拿**電池**與**閃光棒**。

**Aspen Falls 報案**

9. 管制中心廣播叫你回話。回辦公室接電話（按紅色大鈕）。
10. 到地下室上巡邏車，**打開追蹤器**，沿 River 路往東，過 Walls 街後見到 Aspen Falls 路標即停車。
    - 路上遇到停車再開標誌**一定要停**，否則扣分；有開警示燈則不必。
11. 現場有位婦人報案。往右邊畫面走，有個行為異常的男子。
12. 先遠遠試著溝通。他會衝上來搶走你的警徽丟進水裡，自己也跳下水。
13. **趁機搜他的衣服**：拿到一串鑰匙與一張駕照。
14. 把**鑰匙丟進水裡**引他上岸。
15. 用**警棍**打兩下制伏，上**手銬**。
16. 帶到車旁再**搜身**——內褲裡有一把小刀。
17. 把他安置在前座，載回警局。

**收押**

18. 進拘留所前，**把槍放進大門旁的保管箱**、關上、拿走鑰匙。
19. 把駕照與小刀放進櫃台前的抽屜。
20. 以攜帶違禁武器的罪名收押（按左邊的門，輸入代號——查手冊的刑法條號表）。
21. 從抽屜拿回手銬。

**高速公路糾紛**

22. 拿回槍，回辦公室接電話——地點在 7th 與 8th 之間的高速公路。
23. 到場後**沿路肩走過去**（不走路肩會出事）。又是 Morales，對方是拒簽罰單的孕婦。
24. 問過孕婦後與 Morales 溝通，**先讓孕婦離開**（原文說選右邊選項）。
    - 手冊規定：孕婦與年長者拒簽時要呼叫主管到場，不是直接帶回。

**巡邏**

25. 一輛白色跑車超速 → 加速跟上看車牌（一般車牌）→ 開警示燈攔下。
26. 開罰單流程：**把駕照插入車上電腦 → 輸入時間 → 輸入違規代號 → 取出罰單 → 交給駕駛人**。
    - **時間一定要輸對。**第四天上法庭時，第一天填錯時間會直接輸掉官司。
27. 黑色車輛超速但是**免稅車牌**（自己人）→ 不攔。
28. 一排車在快車道慢行 → 攔下最前面那輛（**Joan Ruiz**）。同樣流程開罰單。他會撂話說法庭見。
29. 一輛車蛇行 → 攔下，對方口齒不清有酒味 → 請他下車做**穩定測驗**
    （多說幾次話、請他看著你的手指，用游標左右移動）。
30. 請他手放車上**搜身**、上銬，帶回警局。
31. 回局後先解開手銬，請他用右下角的**酒精測試器**吹氣，機器印出報告。
32. 個人物品放進櫃台前抽屜，以酒駕收押。

**Palm Mall**

33. 回電管制中心：Palm Mall 發生傷害事件——那是 Marie 上班的地方。
34. 開警示燈前往（Rose 街左轉，見 Palm Mall 路標右轉）。
35. 停車場旁有救護車。受害者是 **Marie**。
36. **上救護車前，先拿走 Marie 手中握著的金鍊子**——這是關鍵證物。
37. 醫院：等醫生消息。Marie 脫離險境但陷入昏迷。
38. 一名記者來問話，語氣很差。回嗆之後他會道歉並**給你一張名片**——留著。

**回犯罪現場（夜間）**

39. **把電池裝進手電筒**，打開手電筒搜證。
40. 在 Marie 車子左邊撿到一枚**銅星勳章**，背面刻有軍籍號碼。

## 第二天：兩個案號

1. 出門前從衣櫃拿 **Marie 的音樂盒**。
2. 到警局重案組。組長給你兩個案號：**199144**（Marie 的案子）、**199137**（相關舊案）。
   並介紹新搭檔 **Pat Morales**。
3. 問辦公室裡看報紙的警員——他提到報社幫忙找目擊者。想起昨晚那張名片，**打電話給記者**請他幫忙。
4. 用電腦（**把電腦卡放進識別器**）→ 選 **Homicide** → **Serial#** → 輸入勳章上的軍籍號碼。
   持有人已死亡，案號 **199124**。
5. 調出三個案子比對：兇器都是軍方 **K-7 軍刀**，前兩案死者腹部都被刻上**五芒星**。
6. 到地下室證物保管室（拘留所大門旁），把**勳章與金鍊子**存入，案號報 **199144**。
7. 到醫院：大廳花店買一朵**玫瑰**，櫃台問到 Marie 轉到 **301 號房**。
   放下音樂盒、送上玫瑰時，她的手指會動一下。

## 第三天：拼出兇手的臉

1. 辦公室公文箱：報社傳回消息，目擊者住 **325 S. 2nd St**（舊工業區）。
2. 到現場，平臺上的手推車後有位流浪婦人（**Carla Reed**）。
3. 她不跟陌生人說話 → **拿出皮夾出示警徽**。
4. 她願意跟你走，但要求連手推車一起帶。後車廂放不下——**用手銬把手推車銬在牆上的水管**。
5. 回警局。她說肚子餓 → 隔壁桌有同事的午餐，拿給她。
6. 開始問話，請她敘述經過。
7. 打開桌上電腦 → **Tools** → **Drawing Composite**（拼臉）。
   - 操作：鍵盤用 TAB 在五官選項間移動，B／N 選左右；臉部下方與左方有左右／上下位移調整。
   - 原文的答案：**眼睛、鼻子、嘴巴、頭髮、鬍子都選左邊第一種，眉毛選左邊第二種；
     眼睛稍偏右，頭髮「非常」偏高**。調到老婦人每一項都說 OK 再選 **Search**。
8. 電腦找出三個人，她指認**中間那個**。調出檔案。
9. 送她回去，**記得拿回手銬**。路上 Morales 要求載她去購物中心打電話。

## 第四天：法庭與第二具屍體

1. 公文箱裡是**傳票**——第一天開罰單的 Joan Ruiz 告上法庭。
2. 上四樓電腦室，**翻主任的桌子**（用「手」在桌子偏左處按幾次）拿走抽屜裡的**汽車追蹤器**。
   - 伏筆在第一天：當時聽到主任跟管制中心通話，追蹤器借出三天，今天正好到期。
3. 到地下室，打開巡邏車右邊置物箱，帶走**測速器**。
4. 開便衣車到 Lytton 地方法院。

**作證**

5. 坐在檢察官旁邊。法警喊起立，法官進場。
6. 檢察官傳你作證，陳述當天經過，指認被告。
7. **交出測速器**列為證據。
8. 辯方無問題，法官宣判被告敗訴。
   - **第一天罰單上的時間填錯的話，這場會輸。**

**複製鑰匙**

9. 回車上，Morales 突然很慌張要去購物中心打電話，**把手提袋忘在車上**。
10. 袋上有一串小鑰匙。**拿去購物中心左邊角落的鑰匙店複製一把**，再把原鑰匙放回去。

**300 W Rose 的命案現場**

11. 無線電通報。前往時**要在 Rose 街上、2～3 街之間下車**。
12. 現場已封鎖，屍體在垃圾車內。Morales 負責拍照。
13. **打開後車廂的手提箱**，拿走**牙籤、小刀、採樣塑膠袋**。
14. 搜死者口袋 → **駕駛執照**。
15. 看死者的手 → 指甲裡有毛髮與皮膚碎屑 → **用牙籤採樣**。
16. 翻開死者 T 恤 → 又是**五芒星**。
17. **拿出筆記本，在死者肚子上按一下**記錄。
18. 驗屍官 Leon 到場，把駕照交給他。
19. 檢查旁邊的廢車車門 → 有其他車子的**油漆轉移** → **用小刀刮下樣本**。
20. 工具放回後車廂。

**回警局**

21. 公文箱：醫院的 Wagner 醫生要你過去。
22. 電腦 → **Homicide** → **New Files** → 建立新檔 **199145**。
23. 地下室證物保管室：交出**毛髮樣本**（說明要做 **DNA 分析**）與**油漆樣本**，案號 199145。

**醫院**

24. 上三樓，醫生說 Marie 情況沒改善。
25. **拿起床尾的病歷表**：點滴應該是 **0.05 單位**，但實際點滴上是 **0.15 單位**。
26. **按床頭呼叫鈕**叫護士，再由醫生確認並調回。

## 第五天：五芒星的第五個點

1. 進門先看佈告欄——全局女警員今天做定期心理測驗。
2. 跟旁邊的同事打招呼：他正把最近的命案現場連起來看是什麼圖案。
3. 電腦 → **Review Case** → 案件 **199145** 有新資料：
   油漆檢驗顯示可能來自一部 **G.M. 1976 年出廠的 Sadean**。
4. **打電話給管制中心**，請他們發出通告：注意金色 1976 Sadean，車主可能持有槍械。
5. 電腦 → **Tools** → **City Map** → **Plot Crime**，用 `*` 標出**四個**命案現場
   （含 Marie 出事現場）→ **Draw Pattern** 連起來 → 再點下推測的第五個位置。
   - 結果指向 **Palm 街，第八街與第九街之間**。
6. 出辦公室前先去**心理醫生辦公室**。裡面沒人，桌上有 **Morales 的檢查報告**：
   長期反抗行為、對權力人物有不理性憎恨、對個人尊重心極低、社會行為不穩定；
   另有**三次在不同案件中破壞證物**的紀錄，警局當時認定是「巧合」。

**Old Nuggts 酒吧**

7. 開白色警車前往推測地點——是一家叫 **Old Nuggts** 的酒吧。
8. 門口停著那輛 **1976 Sadean**，車上有白色刮痕。
9. 後車廂拿小刀與塑膠袋，**刮下車子的油漆當證物**。
10. **把汽車追蹤器放到車子底下**。工具放回後車廂。
11. 進酒吧。Morales 說她到後面看看。
12. **用「眼睛」先看打撞球的人**，等一會兒會有另一個人進來——就是拼臉拼出來的那個。
13. **趕快從物品欄選出槍，保持對著歹徒**。他走到球桌另一邊時**先不要開槍**，
    等他先射擊才能反擊。
14. 他開槍後你還擊（可能沒打中），他奪門而出。

**追捕**

15. 衝出酒吧，叫 Morales 上車，**響警笛**，**打開追蹤器**慢慢跟。
16. 他轉往高速公路後停了下來——到現場發現他**自撞翻車**。
17. **先執行勤務**：把**閃光棒**放在車道上維持安全，再處理現場。
18. 死者身上沒有證件，但**車鑰匙還插在鑰匙座上**，拿下來。
19. 驗屍官 Leon 到場，請他有新發現務必通知你。
20. **用鑰匙打開後車廂**：五包古柯鹼，用塑膠防水套包好。
21. 一位警員來找你，**Morales 自告奮勇說她會處理這些證物**。

**回警局**

22. 公文箱：醫院希望你多去看 Marie。
23. 四下無人時，**用複製的鑰匙打開 Morales 的抽屜**：裡面有張紙條，寫著她**置物櫃的密碼**。
    小心把抽屜關上。
24. 地下室：把油漆樣本存入 **199145**，希望與上次的油漆比對。
25. 醫院看 Marie。

## 第六天：收網

1. 到辦公室跟組長打招呼，得知驗屍官 **Leon** 有重大發現。
2. Morales 還沒到，先開電腦看 **199145**——檔案上寫**只有四包**毒品，但你找到的是**五包**。
3. 趁她還沒來，**用複製的鑰匙搜她的抽屜**（紙條上是置物櫃密碼），沒有毒品——
   應該在**女子更衣室**的櫃子裡。
4. 到一樓，女更衣室門外站著清潔工 **Stump** 先生。
5. **先進男更衣室**：把新的衛生紙**全部塞進馬桶**再沖水，水流不走就會溢出來。
6. 出去**叫 Stump 去修**。
7. 趁沒人**進女子更衣室**，找到 Morales 的櫃子（**左排第一個**），用抽屜裡抄到的密碼打開
   ——一整包古柯鹼。
8. **用筆記本記下**，趕快離開。
9. 回樓上向組長報告。他會派人 **24 小時監視** Morales。

**驗屍官**

10. 到地下室找 Leon（Morales 不進去）。桌上有個大信封：**一本宗教書籍、一枚邪教戒指、
    Marie 的項鍊**。
11. Leon 回來後確認那具屍體是 **Steve Rocklin**，另外給你一疊**你自己的剪報**——
    你的照片上被畫了五芒星。地址是 **500 W Peach**。

**醫院**

12. 上車先去醫院。**把項鍊給 Marie 掛上**——她醒了過來。

**500 W Peach 火場**

13. 一上車就收到無線電：500 W Peach 大火——正是 Leon 給的地址。
14. 到場後**先把後車廂的工具拿出來**，等火滅。
15. 問消防隊長：**可能是蓄意縱火**，可以進去調查。
16. 客廳地上的殘骸底下：一張 **Michel 和 Jessie Bains** 的合照——**Jessie Bains 有個哥哥**。
17. 另一個房間：地板上畫著**五芒星**，還有一大灘血跡與毛髮 → **刮取樣本**。

**陸軍招募站**

18. 到 Palms Mall（Morales 要打電話）。旁邊就是**美國陸軍招待所（Army）**。
19. 表明身分，出示照片，說明要查 **Michel Bains** 的資料。
20. 軍官給的檔案：傑出的軍人，直到他唯一的弟弟 **Jessie Bains** 被警員擊斃——
    此後轉為暴力傾向，曾攻擊兩名弟兄，每況愈下，成為宗教狂熱份子。

**心理醫生與地址**

21. 回警局把資料給 **Aimes 醫生**（心理醫生）看：對方是**精神分裂**的病人，要非常小心。
22. 再看一次照片：門柱上寫著 **"522W alm"**，有一個字被遮住——應該是 **Palm**。

**申請搜索票**

23. 開車到 **522 W Palm**：鐵門深鎖、窗戶有鐵欄杆、敲門無人應。
24. 回警局把身上的證物**先存進證物保管室**。
25. 到 **Lytton Court** 找法官。光是開口不會給——**出示剪報、說明查到的線索、再出示照片**，
    法官才會開搜索票。

**攻堅**

26. 帶著搜索票回到那棟房子，現場已有一隊人員待命。
27. 走到門旁，**拿出點 44 自動手槍**（用「槍」在自己身上按一下）。
28. 向裝甲車下令撞門。
29. **進屋前先檢查門的兩邊**，確定沒有人才慢慢走進去。
30. 沙發後突然冒出一個人開槍——**還擊擊斃**。
31. 看到另一個身影移動 → **大喝「不准動」** → 走出來的是 **Michel Bains**，投降。
32. **走到他背後上手銬**，交給趕來的警官。

**暗門**

33. 屋裡搜不到毒品。搜到沙發時發現**椅墊是新的** → 翻起來 → 下面有個**搖控器**。
34. **按「8」** → 壁爐出現一道**暗門**。
35. 走進去：桌上是製造古柯鹼的工具。
36. 準備出去時，樓梯口突然有人開槍 → **回身還擊**。
37. Morales 走進來，走向死者，**撿起地上的槍對著你**——千鈞一髮之際，
    監視她的警員衝進來把她制伏。

**結局**

38. 回到醫院。Marie 已經可以開口說話，並告訴你一個消息：**她懷孕了**。
