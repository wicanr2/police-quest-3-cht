# 出處

1990 年代台灣電腦遊戲雜誌上的《警察故事3》代理商廣告與介紹。

| 檔案 | 內容 |
|---|---|
| `16.jpg` | 全頁廣告，**印刷頁碼 15**（檔名的 16 是掃描序號，不是頁碼）。標語逐字：「扮演維護正義的超級警探!!」「警察故事3」「一部最真實、最具震憾性的偵探冒險遊戲」「SIERRA公司年度立體文字冒險遊戲鉅獻」。頁面下緣另有兩行：「即將秘密發行」「敬請密切注意出片日期」，其中「秘密」二字放大加粗。原文寫作「震憾」（非「震撼」）、「最眞實」用眞的異體，此處照錄 |
| `4.jpg` | 中文介紹跨頁（雜誌頁碼 6–7）。標題「陰謀——警察故事3」，含 Jim Walls 具名專文（中譯）、六張實機畫面，以及「特色」欄：「真人實景，毫不含糊！」「無論是高速公路上的追逐或是與歹徒面對面決鬥的動作場景，皆流暢逼真。」「警笛、槍聲、碰撞、打鬥等音效做得出神入化。」「操作採 SIERRA 式圖形指令，不必像第二代一樣還得鍵入英文訊息！」 |

**「警察故事3」這個中文名就是依這兩頁定案的**——它是當年台灣代理商與雜誌實際使用的名稱。
